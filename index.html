Alert Reader

A small tool for collecting public links from selected email alerts.

The current connector supports SEEK alerts delivered to Gmail. It checks only messages in the label Alert Reader/SEEK and checks the sender before reading an alert. It requests Gmail read-only permission. Google grants that permission at mailbox level; the reader enforces the label restriction.

The reader cannot send, change or delete emails. A missing label stops the intake. Email bodies, subjects, sender addresses and Gmail message IDs are not saved to the link feed.

This page describes the tool. Connected accounts, saved links and the workspace are private. There is no public sign-up.
